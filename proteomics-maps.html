Workflow

How the proteomics maps are generated

Each proteomics panel is turned into an annotatable interaction map in five steps. The same workflow applies to every system-focused dataset.

  1. 1

    Proteomics panel

    Input: measured proteins

    A proteomics panel (for example Olink panels on inflammation and metabolism) provides the list of proteins measured for a given system.

  2. 2

    GO top-level extraction

    Output: proteins grouped per GO top level

    Proteins are annotated with Gene Ontology and mapped onto its top-level terms, giving broad functional groups per panel.

  3. 3

    Knowledge graph query

    Output: interaction network per top level

    For each group, the Clinical Knowledge Graph is queried for reactions among the mapped proteins.

  4. 4

    SBML conversion

    Output: SBML (XML) file

    Each interaction network is converted to SBML, the XML-based standard for systems biology models.

  5. 5

    Annotatable map

    Output: Minerva map

    The SBML files are uploaded to Minerva as maps that can be annotated, explored and overlaid with data.

Background

1. Panels

Targeted proteomics panels measure a defined set of proteins. Panels differ in focus, so each one covers a different part of the biology of a system.

2. Gene Ontology

The Gene Ontology (GO) is a hierarchical vocabulary describing biological processes, molecular functions and cellular components. Its top-level terms are the broadest categories, which makes them a practical way to split a panel into interpretable groups.

3. Clinical Knowledge Graph

The Clinical Knowledge Graph (CKG) integrates omics data, biomedical databases and literature into one graph of proteins, their relationships and clinical context. Querying it for the proteins in a GO top level returns the known reactions among them.

4. SBML

The Systems Biology Markup Language (SBML) is an XML-based exchange format for models of biological processes. Converting the networks to SBML makes them readable by standard systems biology tools.

5. Minerva

Minerva is a web platform for visualizing and annotating molecular maps. Uploaded maps can be searched, annotated and combined with overlay data, the same way as the post-COVID disease map.
